def buscar(query, base, index, k=5):
    q = embedding(query).reshape(1, -1)
    distancias, indices = index.search(q, k)
    resultados = []
    
    for j, i in enumerate(indices[0]):
        distancia = float(distancias[0][j])
        score = calcular_score(distancia)
        
        # Modificación exacta requerida:
        if score > 0.4:
            resultados.append({
                "texto": base[i],
                "distancia": distancia,
                "score": score,
                "indice": int(i)
            })
    return resultados

Pregunta 2 (ID: 35) [1 punto]

Enunciado: Compare resultados usando IndexFlatL2 e IndexFlatIP. Explique diferencias observadas.
Respuesta Teórica:

    IndexFlatL2: Utiliza la Distancia Euclidiana (L2​). Mide la longitud de la línea recta entre dos puntos en el espacio geométrico. Un valor de 0 significa máxima similitud matemática y crece hasta el infinito a medida que los conceptos se distancian.

    IndexFlatIP: Utiliza el Producto Interno (Inner Product). Si los vectores se encuentran normalizados, equivale exactamente a la Similitud de Coseno. Evalúa el ángulo de dirección de los vectores, donde valores más altos significan mayor similitud.

    Diferencia observada: El orden de prioridad (ranking) de los resultados varía. Mientras que L2​ se ve afectado por la magnitud espacial de los embeddings, IP prioriza la orientación conceptual interna, haciendo que textos largos o cortos alteren su relevancia según el índice utilizado.

Enunciado: Construya un mini sistema semántico completo que incluya embeddings, índice FAISS, score, filtrado, logging y persistencia básica. Luego explique fortalezas, limitaciones y posibles usos empresariales.
Respuesta (Código):

import numpy as np
import faiss
import json
from sentence_transformers import SentenceTransformer

# 1. Inicialización de componentes y Persistencia básica de datos
model = SentenceTransformer("all-MiniLM-L6-v2")
base_datos = ["servidor empresarial seguro", "pizza italiana tradicional"]

# 2. Generación de Embeddings e Indexación FAISS
vectores = np.array([model.encode(t).astype("float32") for t in base_datos])
indice_faiss = faiss.IndexFlatL2(vectores.shape[1])
indice_faiss.add(vectores)

# 3. Función del Sistema con Filtrado, Score y Logging incorporado
def mini_buscador_semantico(query, umbral=0.4):
    # Logging básico en consola
    print(f"[LOG] Iniciando búsqueda semántica para: '{query}'") 
    
    q_vec = model.encode(query).astype("float32").reshape(1, -1)
    distancias, indices = indice_faiss.search(q_vec, 1)
    
    distancia_l2 = float(distancias[0][0])
    score_similitud = 1 / (1 + distancia_l2) # Mapeo de score
    
    # Filtrado por umbral de calidad
    if score_similitud >= umbral:
        resultado = {"texto": base_datos[indices[0][0]], "score": score_similitud}
        print(f"[LOG] Resultado encontrado con éxito.")
        return resultado
        
    print(f"[LOG] Ningún resultado superó el umbral de {umbral}.")
    return None

Análisis del Sistema:

    Fortalezas: Ofrece búsquedas exactas e inmediatas en memoria para catálogos pequeños, siendo un sistema sumamente liviano y autocontenido.

    Limitaciones: Carece de escalabilidad horizontal. Al emplear un índice de fuerza bruta (Flat), el consumo de memoria RAM se dispara linealmente con millones de registros y carece de persistencia nativa en disco para el índice.

    Usos Empresariales: Ideal para la automatización de preguntas frecuentes (FAQ) en chatbots corporativos o enrutamiento automático de tickets de soporte técnico técnico hacia el área correcta.

def buscar_multidominio(query, sistema):
    # Solicitamos los top 10 resultados para abarcar múltiples dominios
    resultados_crudos = sistema.buscar(query, k=10)
    
    agrupados = {
        "animales": [],
        "vehículos": [],
        "tecnología": []
    }
    
    for item in resultados_crudos:
        # Filtrado: omitir si no cumple con el score mínimo exigido
        if item["score"] < 0.4:
            continue
            
        posicion = item["indice"]
        
        # Mapeo y segmentación según los rangos del dataset 'base' original
        if 0 <= posicion <= 4:
            agrupados["animales"].append(item["texto"])
        elif 5 <= posicion <= 9:
            agrupados["vehículos"].append(item["texto"])
        elif 15 <= posicion <= 19:
            agrupados["tecnología"].append(item["texto"])
            
    return agrupados

def calcular_score(distancia):
    """
    Convierte algebraicamente la distancia Euclidiana en una métrica
    de confianza acotada entre los valores 0 y 1.
    """
    return 1 / (1 + distancia)

Pregunta 4 (ID: 46) [2 puntos]

Enunciado: Construya un mini recomendador semántico que sugiera textos similares a partir del historial de búsquedas realizadas.

class RecomendadorSemantico:
    def __init__(self, buscador_sistema):
        # Almacena una referencia al buscador principal del sistema
        self.sistema = buscador_sistema
        self.historial_consultas = []

    def registrar_consulta(self, query):
        # Almacena el rastro de la consulta en la lista del historial
        self.historial_consultas.append(query)

    def obtener_sugerencias(self, k_sugerencias=3):
        # Validación de seguridad en caso de historial vacío
        if not self.historial_consultas:
            return []
            
        # Extrae la última búsqueda registrada como pivote de interés actual
        ultima_busqueda = self.historial_consultas[-1]
        
        # Buscamos los elementos semánticamente más cercanos.
        # Se solicita k+1 previendo que el top 1 sea idéntico a la query original.
        resultados = self.sistema.buscar(ultima_busqueda, k=k_sugerencias + 1)
        return resultados

Pregunta 5 (ID: 48) [2 puntos]

Enunciado: Implemente una función que compare múltiples queries simultáneamente y devuelva los textos más relevantes para todas ellas.
Respuesta (Código):

def buscar_multi_query(queries, sistema, k=3):
    # 1. Generamos los embeddings para cada una de las consultas provistas
    vectores_queries = [embedding(q) for q in queries]
    
    # 2. Calculamos el "vector promedio" mediante la media aritmética (axis=0).
    # Esto representa geométricamente el punto central de la intersección semántica de las queries.
    vector_centroide = np.mean(vectores_queries, axis=0).reshape(1, -1)
    
    # 3. Realizamos la búsqueda vectorial utilizando el índice FAISS global del sistema
    distancias, indices = sistema.index.search(vector_centroide, k)
    
    resultados = []
    for j, i in enumerate(indices[0]):
        resultados.append({
            "texto": sistema.base[i],
            "score": calcular_score(float(distancias[0][j])),
            "indice": int(i)
        })
    return resultados

Pregunta 7 (ID: 40) [1 punto]

Enunciado: Compare el comportamiento del sistema usando bases pequeñas especializadas frente a bases grandes mezcladas.
Respuesta Teórica:

    Bases Pequeñas Especializadas: Exhiben una alta precisión (Precision) en el dominio configurado. Las distancias calculadas entre los elementos vecinos son compactas, estables y el sistema está completamente a salvo de falsos positivos conceptuales, sacrificando variedad por exactitud.

    Bases Grandes Mezcladas: Se incrementa de forma drástica el ruido semántico y las colisiones de vecindad. Al cohabitar dominios dispares (tecnología, comida, animales), se reduce la nitidez del motor de búsqueda en los límites de los clusters vectoriales. Las palabras homónimas o ambiguas tienden a mezclarse entre sí en las consultas del top-k, volviendo indispensable la implementación técnica de capas de filtrado híbrido por metadatos (pre-filtering o post-filtering).
